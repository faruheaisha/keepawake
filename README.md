# KeepAwake 防休眠

一个本地运行的 Windows 桌面工具，让电脑在编译、下载、演示或其他长任务期间保持唤醒。打开应用，选择场景与时长，即可开始保护；关闭窗口后可以继续在系统托盘中管理。

Windows 10 / 11 · 中文 / English · 无账号 · Apache-2.0

## 开始使用

下载[发布页](https://github.com/faruheaisha/keepawake/releases)中的 `KeepAwake.exe` 并双击打开。它是独立桌面程序，无需浏览器或额外安装运行库。也可以选择便携压缩包或当前用户安装包。

1. 选择日常工作、演示投屏或长任务场景。
2. 选择保护时长，或指定未来的结束时间。
3. 根据需要调整屏幕常亮和防止自动锁屏，点击“开始保护”。
4. 在窗口或托盘中暂停、恢复或停止保护。

关闭窗口默认收起到托盘，保护不会因此停止。托盘菜单可单独退出界面，或同时停止保护并退出。桌面设置中的“登录后启动到托盘”只启动界面；它与可选的保护自动恢复任务相互独立。全局快捷键 `Ctrl + Alt + K` 默认关闭，启用后用于开始、暂停或恢复保护；如果快捷键已被占用，应用会提示。

“防止自动锁屏”会按设置发送轻量的输入心跳。它不能覆盖组织策略、手动锁屏、合盖动作或所有硬件休眠行为。请勿把电源请求等同于对物理设备永不休眠的保证。无需防锁屏时可以关闭该选项。

## 任务与 MCP

桌面窗口中的“任务”显示外部保护申请及其结束时间，可以单独释放一个任务；“停止保护”会停止全部申请。也可以输入一个正在运行的进程 ID，绑定该进程实例；进程退出后，其保护会自动释放。任务都有有限有效期，多个任务不会因为其中一个完成而全部释放。

可选的 `KeepAwake-MCP-win-x64.zip` 提供本机 MCP 接入。解压后，按包内 README 配置客户端启动 `KeepAwake.Mcp.exe`。AI 客户端可以查看状态，并为自己的任务申请、续期和释放保护；不提供任意命令执行或系统设置修改。任务名称和结果会交给所选客户端，该客户端可能将其发送给 AI 服务，因此请勿把秘密放进任务名称。

也可以在包含命令行工具的便携包或源码目录中运行：

```bat
ka.bat run -- your-command argument1 argument2
```

包装器在前台命令运行期间持有独立保护，转发其退出码；异常结束后由监控进程回收申请，有限期作为兜底。它跟随所启动命令的生命周期；如果命令自行启动脱离的子进程并提前退出，请为实际长任务单独申请保护。

## 自动保护与电池

“自动保护”可添加同一天内的时间表，选择星期、开始和结束时间；也可选择一个 `.exe`，在该完整路径的程序实例运行时保护。每条规则独立选择屏幕常亮和防锁屏。规则需要桌面或托盘保持运行，不唤醒已休眠的电脑，也不补跑已经结束的时段。错过开始时间后，在当前时段内打开应用会补上剩余时段。

手动停止或释放规则任务后，当前时段或当前程序实例会被跳过；下一时段或新的程序实例可以再次触发。修改并保存一条规则视为新的授权。时间表按 Windows 本地时区运行，夏令时重复小时使用一次连续时段，不存在的时刻顺延至有效时刻；跨午夜可拆为两条规则。退出桌面后不会再创建新规则任务，已有任务按列表中的有效期释放，程序规则最多保留至最近一次续期后的 15 分钟。

设置中的“电池策略”可选择继续保护、允许熄屏及自动锁屏，或停止全部保护，并为电池供电设置最长保护分钟数。拔电动作在连续两次已知读数后生效；未知供电状态不代替用户作决定。危急电量会停止保护。低电量允许熄屏时也暂停输入心跳，恢复阈值保留 10 个百分点的迟滞。

## 隐私与数据

应用不要求登录，也没有遥测、广告或自动更新服务。设置、运行状态和日志默认保存在 `%LOCALAPPDATA%\KeepAwake`；可以通过 `KA_DATA` 环境变量指定其他数据目录。单文件 EXE 首次运行时会将内嵌引擎释放到该数据目录中的内容哈希文件夹。

任务记录包含来源、任务名称、到期时间和能力令牌的哈希，不保存原始令牌。桌面窗口可以预览并导出字段白名单诊断 JSON；该诊断默认不包含账户名、路径、任务名称或令牌。可选的旧网页面板仅在用户显式启动时监听本机回环地址，桌面版不依赖它。详见 [隐私说明](PRIVACY.md)和[安全说明](SECURITY.md)。

## 从源码构建与验证

在 Windows 上使用系统自带的 Windows PowerShell 5.1 和 .NET Framework C# 编译器：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File packaging\build.ps1 -Stage -Smoke
powershell -NoProfile -ExecutionPolicy Bypass -File tests\ka-ci.ps1 -Gates
powershell -NoProfile -ExecutionPolicy Bypass -File tests\probe-desktop.ps1
```

构建产物位于 `dist/`。安装包还需要 Inno Setup。可选 MCP 程序使用 .NET 10 官方 SDK；其单独的构建和客户端配置说明位于 `mcp-server/README.md`。修改电源计划或计划任务的完整系统测试应在可丢弃的 Windows 虚拟机中进行。

已有验证和平台限制应以本次构建与发布说明为准。不同 Windows 版本、设备固件、电池状态、合盖、远程桌面和物理待机方式仍需分别验证。当前程序未签名，Windows 可能在首次运行时显示安全提示。
