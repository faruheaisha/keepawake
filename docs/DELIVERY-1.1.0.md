# 1.1.0 审核落地与验收

产品主入口为 Windows 桌面 EXE。既有桌面设计与素材已合入主工作区，`panel.bat` 和安装版快捷方式均指向桌面程序。旧网页面板只保留为显式启动的可选工具。

## 缺陷修复

原始问题和复现前提见[审核记录](项目全面审核-2026-10-31.md)。以下列出持续回归入口；故障注入与真实进程测试分开理解。

| 问题 | 落地 | 验证入口 |
| --- | --- | --- |
| B01 电池位标志 | 更正常量，保留未知状态；危急电量停止并撤销任务 | `probe-audit-fixes.ps1`、`probe-lease-store.ps1` |
| B02 多屏鼠标 | 虚拟桌面标志与发送数量校验 | `probe-audit-fixes.ps1`；物理多屏仍需验收 |
| B03 参数应用 | 比较完整运行参数，响应包括重声明周期 | `probe-runtime-identity.ps1`、桌面真实会话测试 |
| B05 起停竞争 | 用户及规范化数据根对应的跨进程操作锁 | `probe-operation-lock.ps1`、`probe-lease-concurrency.ps1` |
| B06–B08 合盖备份 | 备份读回后才写入；检查退出码、失败回滚并验证；拒绝跨计划与损坏备份 | `probe-lid-audit.ps1`；真实电源设置由一次性 VM 测试 |

| B10 JSON 并发 | 唯一临时文件与原子替换，事务共用操作锁 | `probe-audit-fixes.ps1` 的 600 次并发写入 |
| B11 证据归属 | 检查实际 worker 的路径、数据根和创建时刻 | `probe-runtime-identity.ps1` |

| 发布与分发 | tag 必须对应构建提交；Windows 10 最低安装版本；精确资产及哈希清单 | Windows CI、发布工作流 |

## 功能落地

| 功能 | 用户入口与边界 | 验证 |
| --- | --- | --- |
| 命令包装 | `ka.bat run -- ...`；跟随前台命令，不追踪脱离的子进程 | 真实退出码 7、命令不存在、强制结束包装器后的回收 |
| 多任务 | 桌面“任务”，可单独释放；全部停止撤销所有任务 | 并发申请、所有权、过期、暂停和停止优先级 |
| MCP | 可选自包含 stdio 包，五个受限工具，无任意 shell | 两个协议会话使用实际引擎独立申请/释放；具体 AI 客户端版本尚未认证 |
| 时刻与暂停 | 自定义结束时间、暂停 15 分钟和恢复 | 跨日、DST 间隙/重复小时、停止取消自动恢复 |
| 诊断导出 | 桌面预览后保存字段白名单 JSON | 不含路径、用户名、任务名称和令牌 |
| 异常通知 | 状态改变时通知，去重 | 不宣称 Windows 勿扰或锁屏下已实际送达 |
| 场景 | 日常工作、演示投屏、长任务 | 参数、时长和跨页草稿保留 |
| 电池策略 | 设置中选择拔电动作与最长保护时间 | 两次已知读数确认、单调时钟、未知状态、十个百分点迟滞；熄屏降级暂停输入 |
| 托盘及快捷键 | 单独登录项；Ctrl+Alt+K 默认关闭 | 单实例、占用冲突、退出和停止语义 |
| 程序规则 | 选择完整 EXE 路径；按 PID 与创建时间区分实例 | 同名不同路径不匹配，不读取窗口标题；程序存在不代表正在工作 |
| 时间表 | 同日时段、指定星期；桌面或托盘运行期间触发 | 错过开始后补当前剩余时段、不补已结束时段；DST 连续区间；手动停止跳过当前发生项 |
| 可访问性 | 原生焦点、键盘按钮/开关、数值方向键、滚动和固定起停栏 | 中英文、小窗口、焦点与对话框自检；真实读屏及 200% 系统缩放仍需人工验收 |

规则退出后的剩余有效期、重新授权、电池动作确认周期及外部客户端隐私说明均写入 README。完整程序路径和规则名称保存在用户本地数据中，不进入默认诊断导出。

## 本地验证与发布边界

- 本机 Windows 11：18 项针对性探针通过；桌面 EXE 的实际窗口、单文件复制运行、保存、真实 worker 起停、暂停恢复和诊断导出通过。后续修改须重跑相关入口。
- 便携包：实际解压后打开桌面并读取隔离状态，程序目录没有生成用户状态。
- MCP：构建使用固定 SDK 与 NuGet 锁文件，分发包含运行时和第三方版权通知；协议验收使用解压后的分发包。
- 发布构建使用单独的 Windows x64 依赖锁，避免改写源码构建的锁文件。打包启动检查与完整界面自检分别执行；四种损坏产物均被拦截，正常包、增加脚本的包和仅增加测试文件的包通过。
- 中文路径的命令入口、七种语言环境及文化格式故障注入通过；重复小时的新日志和旧日志不确定性有独立回归覆盖。
- 完整系统套件、安装卸载及最终发布以 GitHub Windows CI 结果为准。本机打包工具安装被自动审批拒绝，因此不把本机安装器验收写成已完成。
- 尚无 Windows 10、ARM64、真实 S3/S0 待机、物理合盖/充放电、多显示器和远程桌面的完整设备矩阵。CI 不能替代这些检查；未签名程序也不等于已通过商店或 SmartScreen 认证。
