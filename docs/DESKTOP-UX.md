## 视觉规范

- 主色 `#01875F`，选中面 `#DDF4E8`，背景 `#FAFCFA`，正文 `#202124`。
- 场景图标 42 DIP，色块 58 DIP；导航图标 25 DIP；操作图标 22–24 DIP。
- 演示场景用蓝色，长任务场景用暖金色；图标、标题和选中边框同时传达含义。
- imagegen 生成品牌 PNG；ICO 使用同一图像转换成 16、24、32、48、64、128、256 像素帧，分别服务资源管理器、窗口、任务栏与托盘。
- SVG、PNG、ICO 全部内嵌 EXE，不下载字体或图标，不依赖 WebView。SVG 渲染仅支持本项目使用的本地几何元素，XML 外部资源解析关闭。

## 晨光视觉层次

保持绿色主色、浅色界面和原有信息层级。页面背景从 `#F6FAF7` 轻缓过渡到 `#EDF5EF`，右上角只有低对比轨道线；白色设置与活动卡片保持阅读对比。首页状态卡从 `#E4F4E9` 过渡到 `#F9F6E7`，右侧插画随待机、保护中、定时完成变化，计时和电源信息留在左侧。三个场景使用书本、投影机、云与服务器图片，保留大功能图标和明确的选中边框。设置插画位于常规设置卡的上半部，活动空状态使用归档托盘，关于使用盾牌与晨光，避免在不同页面重复同一个主体。

9 张插画由内置 imagegen 生成，1536 × 1024，保留真实 Alpha 透明通道，均保存在 `desktop/assets/` 并内嵌 EXE；完整映射和最终提示词见 [ART-DIRECTION.md](ART-DIRECTION.md)。新的 `sparkle.svg` 属于本地 SVG 系统，连同原有图标共 17 个。原生控件 `Atmosphere.cs` 负责背景、晨光卡与插画动效，不增加浏览器依赖。运行时准备至多 512 像素宽的纹理，按控件大小缓存绘制结果。

插画以 60 ms 间隔刷新，浮动幅度仅 2 DIP，SVG 星芒反向轻微移动；运行状态增加小型绿色呼吸点。场景图标悬停时平滑上浮 3 DIP。窗口隐藏时停止插画计时器，最小化时跳过重绘；控件销毁时释放计时器；系统关闭 UI 视觉效果时使用静态展示。装饰控件不进入键盘焦点，也不覆盖可点击操作或计时文本。

## 操作顺序与状态

信息按任务分层：首页只有状态、场景、时长、开关和固定操作栏；设置分为通用与保护；活动分日志与诊断；关于集中版本、数据位置、隐私和能力边界。首页不展示安装就绪、仅本机运行等实现说明，也没有编号步骤或重复品牌横幅。

1. 选择日常工作、演示投屏或长任务。首次推荐 60 / 60 / 120 分钟；用户手动选过时长后，切换场景保留该时长。
2. 设置时长，再调整屏幕常亮和防锁屏。自定义弹窗取消后不改原选择。
3. 点击底部固定的「开始保护」，查看真实运行时长、剩余时间和电源来源。

运行时主按钮始终是「停止保护」。修改草稿后，另一个「应用更改」按钮出现；应用后重新计时，改回原值后该按钮消失。导航保留未应用的草稿，保存写下次启动的默认值。状态轮询与动作串行执行，但后台轮询不清空草稿、不替换按钮文字。计时以单调时钟推算快照后的变化，避免系统时钟调整造成跳动。

成功起停与场景切换直接更新状态，不额外弹提示。保存、复制与计时结束显示短暂反馈，通常不占布局空间。操作失败显示简短通知，提供详情、重试和关闭；原始异常只出现在详情中。读取日志或诊断失败不抹掉已经确认的保护状态。

数值输入为 44 DIP 高的圆角栏：数值与单位居中，加减按钮清楚分开，焦点用绿色边框表达，支持直接输入和方向键。心跳间隔范围 10–3600 秒，低电量阈值范围 0–90%，与核心一致。低电量阈值控制是否允许熄屏，不代表停止后台保护。定时弹窗用两张卡区分持续时间和结束时刻；日期可直接编辑或由日历选择，结束时刻必须在未来七天内。

默认窗口完整显示常用操作；860 × 560 DIP 的小窗口可滚动内容，起停操作栏固定可见，无横向滚动。支持键盘焦点、空格切换选项、Ctrl+Enter 起停、F5 刷新、Esc 收起到托盘。

## 验证

`tests/probe-desktop.ps1` 将 EXE 单独复制到中文和空格路径，实际打开页面，再验证单实例唤起、退出、偏好保存、真实定时 worker、停止和日志。GUI 自检验证 17 个 SVG 与 9 张插画透明度、动画帧推进和隐藏后停止再恢复、控件圆角外无黑色背景、数值加减、跨页面草稿、场景切换保留时长、取消定时、停止与应用两个动作的独立性以及修改后还原。预览覆盖启动中、首页、设置、活动、诊断、关于、定时弹窗、英文和小窗口，并注入保护中与定时完成 UI 状态检查插画切换；这两张为视觉状态样例，真实 worker 的起停由探针另行验证。每张同时生成 `DrawToBitmap` 与 `CopyFromScreen` 实际屏幕截图，分别检查自绘内容与 Windows 实际呈现。

目前这些检查在开发机 Windows 11 上运行。商店提交、代码签名以及不同 Windows 版本和架构的实机验收仍属于发布环节；界面验证不等于已经通过商店审核。
